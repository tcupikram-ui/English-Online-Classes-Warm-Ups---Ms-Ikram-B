# English Warm-ups · A1–A2 Kids Level

Play, Learn, Repeat! A colourful, interactive website of five-minute English warm-up games for young learners, created by Ms Ikram Boudaoud (The Fed Up Teacher).

## What's inside
12 ready-to-play activities in four categories:
- Everyday English: Time & Date, Weather & Clothes, Where Is It?, Dinar Expert
- Classroom Talk: Class Phrases
- Grammar & Tenses: Present Simple, Time Markers, Negative Sentences, Verb Detective, Irregular Verbs
- Compare Things: Comparatives, Superlatives

## Features
- Search and category filters to find a warm-up quickly
- Each activity opens in one click and runs as a 5-minute game
- Works on phones, tablets, and computers
- Single HTML file, no installation needed
